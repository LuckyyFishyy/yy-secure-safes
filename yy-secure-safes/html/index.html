Safe Passcode 🔐
----
Enter your code, then press Enter. Cancel to close.
Safe Settings ⚙️
Change Passcode 🔁 Set a new passcode for your safe
Craft Safe Key 🔑 Turn a blank key into a safe key
Upgrade Storage 📦 Use an upgrade item to expand storage
Remove Upgrade ➖ Remove the last upgrade and reclaim the item
Apply Vault Seal 🧪 Temporarily blocks breach attempts
Install Anti-Drill Plate 🛡️ Disables drilling on this safe
Install Alarm Module 🚨 Adds a breach alarm with a warning light
Remove Alarm Module 🧰 Remove the alarm module from this safe
Move Safe 📦 Relocate your safe (must be empty)
Press [UP/DOWN] to navigate, [ENTER] to select, [ESC] to close
Placement 📍
Aim to position the safe.
