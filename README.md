# yy-secure-safes
Secure safes is a safe system for QBox/QBX servers that lets players place safes in the world, lock them with a 4‑digit code, and store items inside. Everything is done with target interactions — no commands needed.

Main features:
- Place safes anywhere with a live preview.
- Lock/unlock with a 4‑digit passcode.
- Optional safe keys that can unlock without the code.
- Breach options (hacking or drilling) with configurable difficulty.
- Breach limits and cooldowns to prevent spam.
- Storage upgrades that increase slots and weight.
- Vault Seal upgrade to temporarily block hacking.
- Anti‑Drill upgrade to block drilling.
- Alarm upgrade with a blinking light and sound.
- Customizable config for tiers, storage, minigame difficulty, and tools.

It’s designed to be easy to configure and fully uses ox_target + ox_inventory.
